# Heart Chain（心链）

一款以「母子关系 / 成长与约束」为主题的 Unity 3D 解谜游戏。玩家操控白色小球在不同关卡中探索，体验从无忧无虑到被迫面对现实的情感旅程。

---

## 项目结构

| 路径 | 说明 |
|------|------|
| `Assets/2D3D维度切换/` | 主要关卡场景 |
| `Assets/2D3D维度切换/开场.unity` | 开场动画场景 |
| `Assets/script/ai/` | 过场、音效、UI 等逻辑脚本 |
| `Assets/script/Player/` | 玩家控制相关 |
| `Assets/bgm/` | 背景音乐与音效 |

## 开场动画（场景：开场）

### 叙事含义

| 元素 | 象征 |
|------|------|
| **小白球** | 孩子无忧无虑的童年 |
| **红球** | 母亲对孩子的约束与期望 |
| **压迫阶段** | 唠叨与规则不断挤压孩子的自由空间 |
| **仰视红球** | 被迫提前面对"大人世界" |
| **缓慢行走** | 失去童真的活力，提前步入现实 |

### 动画阶段

1. **无忧无虑** — 小白球欢快蹦跳、自转、挤压拉伸；轻快背景音乐
2. **红球登场** — 红球从侧面出现，唠叨音效响起，孩子开始犹豫
3. **持续压迫** — 红球步步紧逼，活动范围缩小，蹦跳变弱，颜色变灰，体积缩小
4. **第一视角仰视** — 切换为孩子视角，红球变得高大并前倾俯身
5. **黑屏过渡** — 天空盒从明亮日落切换为阴沉
6. **失去活力** — 凄凉钢琴曲，小白球缓慢、沉重地向前行走，然后进入下一关

### 使用方法

1. 在 Unity 中打开 `Assets/2D3D维度切换/开场.unity`
2. 选中 `OpeningDirector` 物体，Inspector 中可调整各阶段参数
3. 运行场景即可预览；结束后自动跳转到 `2D3D维度切换` 场景

### 主要参数（OpeningDirector）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `bouncePhaseDuration` | 4 | 无忧无虑阶段时长（秒） |
| `oppressionDuration` | 3.5 | 红球压迫阶段时长（秒） |
| `redBallToweringScale` | 4 | 仰视时红球最终缩放 |
| `finalBallScaleRatio` | 0.75 | 失去活力后小白球大小比例 |
| `slowWalkDuration` | 5 | 结尾缓慢行走时长（秒） |
| `nextSceneName` | 2D3D维度切换 | 结束后跳转的场景名 |

### 音效资源

- 欢快背景：`Assets/bgm/小美好，轻快飞扬...mp3`
- 唠叨音效：`Assets/bgm/唠叨的声音...mp3`
- 凄凉钢琴：`Assets/bgm/催泪煽情钢琴曲...mp3`

## 1111 场景 → 3:4 竖版海报

### 第一步：设置预览比例

1. 打开 `Assets/2D3D维度切换/1111.unity`
2. 看 Unity 上方 **Game（游戏）** 窗口
3. 点左上角比例下拉框（默认可能是 Free Aspect）
4. 点最下面 **+** 号，新建比例：
   - 名称填：`Poster 3:4`
   - 宽填 `1080`，高填 `1440`（或其他 3:4 尺寸，如 750×1000）
5. 选中刚建的比例，Game 窗口就会变成竖版

### 第二步：调整构图

1. 在 Hierarchy 选中 **Main Camera**
2. 用 **Scene 视图** 移动、旋转相机，或用 Inspector 改 Position / Rotation / Field of View
3. 一边调一边看 **Game 窗口**，直到 Heart、红球、白球等主要元素在竖版画面里排好看
4. 竖版画面上下空间多、左右空间少，可能需要：
   - 相机拉近一点（减小 Field of View 或把 Z 往场景方向移）
   - 把重要物体往画面中间靠

### 第三步：导出海报图片

场景里的 **Main Camera** 已挂好 `PosterCaptureHelper` 脚本：

1. 点击 Unity 上方 **播放 ▶**
2. 确认 Game 窗口比例仍是 **Poster 3:4**
3. 按键盘 **F12**
4. 海报会自动保存到项目文件夹外的 **`Posters/HeartChain_Poster_3x4.png`**
   - 完整路径：`Heart Chain/Posters/HeartChain_Poster_3x4.png`
5. 停止播放

也可以在 Inspector 里右键 `PosterCaptureHelper` 组件 → **Capture Poster Now** 立即截图。

### 常用海报尺寸（都是 3:4）

| 用途 | 宽 × 高 |
|------|---------|
| 一般宣传 | 1080 × 1440 |
| 高清打印 | 1500 × 2000 |
| 社交媒体 | 750 × 1000 |
