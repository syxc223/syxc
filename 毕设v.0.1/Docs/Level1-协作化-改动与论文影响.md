# 第一关《消失的钥匙》协作化改造说明

> 实现日期：2026-10-23 ｜ 改造前场景备份：`Backups/Level1_pre_coop.unity`
> 定位：**教学关** —— 把协作动词（分工、转述、同时、看门人）在低强度下全部教一遍，第三关《双生仓库》再综合运用。

---

## 1. 协作弧线（改造后）

**分头调查 → 互相转述拼出谜底 → 推开大门 → 轮流为对方开出口闸门 → 各自抵达出口**

| 环节 | 协作动词 | 实现 |
|---|---|---|
| 调查 | 分工 | 11 个必查目标按玩家归属拆半（P1 侧 5 个 / P2 侧 5 个 / NPC 皆可），读错对象会被引导"让同伴来看"，且不推进台词、不计入进度 |
| 谜底 | 信息不对称 | 两条**私有关键线索**只对发现者本人显示：P1 在「门前告示」第二句发现「锁孔里什么都没有」；P2 在「壁画」第二句发现「金漆未干、是画上去的」——必须口头转述才能拼出"锁是画的" |
| 金字 | 节奏（演示可调） | 合计调查 **≥4 个目标**（`KeyPuzzleManager._searchesToReveal`，0 = 查完全部必查）即出金字，演示不必翻全屋 |
| 推门 | **单人可推（演示模式）** | 金字出现后单人按一次 E 即触发揭示演出。"两人 3 秒内各按一次"保留为可选开关 `_requireBothPlayersToPush`（默认关） |
| 出口 | 看门人 | 北半间新增「出口闸门」+ 南北两块压力板（OR）：一人踩板另一人先过，再交换（复用第三关的 `PressurePlate`/`LockedDoor`） |

> 落位说明：计划原定把闸门放在拱口，实测发现**拱口本身就装着"大门"（画锁之门）**且通道仅 1.47 宽，故闸门移到北半间必经之路（z≈14）——机制不变。
>
> **演示调整（2026-10-23 追加）**：为控制在答辩现场的演示时长——① 金字门槛由"查完全部 11 个"改为"合计 ≥4 个"（场景里可调）；② 推门由"双人 3 秒同按"改为单人可推（双人模式保留为 `_requireBothPlayersToPush` 开关，默认关）。

## 3. 场景改动

- 北半间 z≈14：两段 `ChamberWall` 横墙把房间拦腰收窄，留 3.3 宽门洞 + 门楣（`ChamberAccent`）；
- `出口闸门`（Cube+DoorMat+NetworkObject+LockedDoor，垂直下沉开启，`_displayName=出口闸门`，开门/关门 HUD 提示）；
- `压力板_闸南` (-4.0, 0.06, 12.6)、`压力板_闸北` (4.0, 0.06, 15.4)，OR 接线；
- **修复既有 bug**：`SM_Door01`（大门）的 BoxCollider 在场景里是 disabled——原来可以不推门直接走进出口。已启用（开门后由 `KeyPuzzleDoor` 自动禁用）；
- 神秘旅人台词（5 段）、门前告示/壁画台词（2 段）、`LevelManager._objectiveText`、大厅任务 1 NPC 的 7 段台词与 `_levelDesc` 全部改为协作版。

## 7. 已知限制

- 私有线索的"仅本人可见"依赖定向 ClientRpc，极端情况下（发送者掉线瞬间）提示可能丢失，无进度影响；
- 双人推门窗口（若开启）为常量 `DOOR_PRESS_WINDOW=3s`，可按手感调整；
- 门槛降低后单人也能集齐 4 个调查并开门——协作性由"线索归属/私有线索/出口闸门"承担，演示时建议两人各读 2 个以体现分工；
- P1/P2 的线索归属按 clientId（0=主机=P1），与出生/出口分配一致。
