# 07 · UI/UX 与视觉打磨

> 本模块补齐 UI（主菜单、登录、HUD、结算、排行榜）并做 HD2D 视觉打磨。UI 脚本逻辑给 Codely，美术风格可再用 04 号文件的 SD 前缀生成 UI 素材。

## 提示词 7-A — 主菜单与登录/注册界面

【目标工具】Codely
【使用时机】联机与后端就绪后
【提示词正文】

```
请基于现有 UIManager.cs 搭建主菜单流程 UI 脚本。要求：

1. 主菜单按钮：登录/注册、创建房间、加入房间、设置、退出。
2. 登录/注册界面：用户名 + 密码输入框（TMP_InputField）、登录/注册切换、错误提示文本；对接 01 号文件的 ApiClient（Login/Register），成功后存 UserSession，回主菜单并显示用户名。
3. 创建/加入房间界面：对接 02 号文件的 Relay（创建显示 join code / 输入 join code 加入）。
4. 状态提示：加载中（连接后端/Relay 时转圈或文字）、失败重试。
5. 统一 UI 风格：暗色半透明面板 + 像素字体（TextMeshPro），标题用「HD2D 奇幻」感。
6. 兼容点：TMP 用 TextMeshProUGUI；Unity 2022.3 API。

请给出 MainMenuController.cs、LoginUIController.cs、LobbyUIController.cs 的完整代码，并说明 Canvas 结构与按钮绑定方式（用代码动态绑定还是 Inspector 拖拽，选一种并保持统一）。
```

【预期产出】主菜单 → 登录 → 建房/加入 的完整 UI 流程脚本，编译通过。

## 提示词 7-B — 游戏内 HUD

【目标工具】Codely
【使用时机】主菜单流程跑通后
【提示词正文】

```
请完善游戏内 HUD（现有 Assets/Scripts/UI/GameHUD.cs）。要求：

1. 显示：当前关卡名、双人协作提示（如「需要两人同时踩下压力板」的引导文案）、本关用时。
2. 提示系统：谜题触发时显示一条短暂提示（如「两人各踩一个压力板开门」），几秒后淡出。
3. 队友状态：显示队友是否已连接/在线；断线时弹「队友已断开」提示。
4. 暂停菜单：返回主菜单、重新开始、设置音量（对接 AudioManager 的 BGM/SFX 音量接口）。
5. 兼容点：Unity 2022.3 + Netcode 1.12.2，断线监听用 OnClientDisconnectCallback。

请给出改造后的 GameHUD.cs 及相关 UI 脚本完整代码。
```

【预期产出】HUD 显示关卡/用时/协作提示，支持暂停与音量设置。

## 提示词 7-D — HD2D 视觉打磨（后处理 + 光影）

【目标工具】Codely
【使用时机】功能齐全后做质感提升
【提示词正文】

```
请帮我把场景调成更有 HD2D 质感的视觉效果。项目已有 Assets/Scripts/HD2D/PixelationFeature.cs（像素化后处理），URP 14。要求：

1. 后处理 Volume：Bloom（轻微辉光）、Vignette（暗角）、Color Grading（暖色调，奇幻感）、景深 Depth of Field（角色清晰背景略虚）。
2. 光影：3D 点光/方向光打在 2D 精灵上形成立体感；说明 URP 14 的灯光设置与阴影参数。
3. 像素化：复用现有 PixelationFeature，说明如何调整像素化强度与后处理顺序（像素化应放在 Bloom/景深之后，达到「像素+光影」的 HD2D 效果）。
4. 关键兼容点：团结引擎 2022.3 的 DepthOfField 没有 focusRange 字段；URP Asset 没有 msaaCount 字段——请用 2022.3 支持的参数替代，并在代码里注释说明。
5. 给出一份可执行的 Volume Profile 参数建议清单 + 必要的脚本（若有）。

请先确认现有 PixelationFeature 的实现方式，再给出打磨方案与参数，避免破坏现有渲染。
```

【预期产出】画面呈现「像素角色 + 立体光影 + 暖色奇幻」的 HD2D 观感，且不报 2022.3 API 错误。
