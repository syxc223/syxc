## 项目定位
- 一款 HD2D 风格（参考《歧路旅人 Octopath Traveler》：2D 像素角色精灵 + 3D 场景 + 动态光影与后处理）的双人合作解谜游戏。
- 玩法核心：两名玩家联网协作，利用「传送门枪 + 激光折射 + 压力板 + 拾取方块 + 机关门 + 出口」等机制解开谜题关卡。

## 引擎与包版本（务必严格遵守，API 不能写错）
- 引擎：Unity 2022.3.62f3c1（团结引擎 Tuanjie）
- 渲染管线：URP 14（com.unity.render-pipelines.universal 14.0.12）
- 联机：Netcode for GameObjects 1.12.2（com.unity.netcode.gameobjects）
- 已接入 AI 插件 Codely（cn.tuanjie.codely.bridge），无需处理它。

## 团结引擎 2022.3 的 API 兼容点（重要，避免你用 Unity 6 语法报错）
- 刚体速度用 Rigidbody.velocity（不是 linearVelocity）
- NetworkConfig 没有 NetworkTickRate 字段（不要设置）
- DepthOfField 没有 focusRange 字段
- UniversalRenderPipelineAsset 没有 msaaCount 字段

## 代码风格约定
- 用 C#，命名空间可省略；中文注释说明「为什么」，关键逻辑用简短英文命名。
- 联机代码遵循 Netcode：服务器权威，状态用 NetworkVariable，动作用 ServerRpc，广播用 ClientRpc。
- 不要破坏现有能跑的功能，优先扩展而非重写。
