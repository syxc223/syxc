# 04 · 角色与美术（Stable Diffusion）

> 本模块所有提示词均为**英文正/负提示词**（SD 对英文响应更好），直接复制到 Stable Diffusion。HD2D 的关键是「像素角色 + 干净背景 + 帧间一致」，务必配合 ControlNet 与固定种子。
>
> 通用参数（正文里不再重复）：
> - 出图尺寸：角色单帧建议 `512×512`，spritesheet 建议 `1024×1024` 或 `512×1024`
> - 采样器：`DPM++ 2M Karras`，步数 `25–30`，CFG `7`
> - 角色统一用**固定种子**（每个角色一个 seed），保证脸型/配色一致

---

## 提示词 4-A — HD2D 通用风格前缀（先建立风格基线）

【目标工具】Stable Diffusion
【使用时机】生成任何角色/场景前，先用它定调
【提示词正文】

**Positive prompt（通用前缀，拼在所有提示词最前面）：**

```
HD-2D style, Octopath Traveler inspired, pixel art character, 16-bit retro JRPG sprite, clean 2D pixel sprite, chibi proportions, bold outlines, vibrant colors, soft 3D lighting, depth of field, fantasy adventure game, high quality pixel art, coherent color palette, no background, plain white background
```

**Negative prompt（通用，拼在所有负面框）：**

```
lowres, bad anatomy, bad hands, extra fingers, missing limbs, blurry, jpeg artifacts, 3d render, realistic, photograph, text, watermark, signature, frame border, grid lines, inconsistent style, deformed, ugly, oversaturated, chromatic aberration, motion blur
```

【预期产出】一组风格统一的像素角色图。确认这组风格符合你想要的 HD2D 观感后，把该风格前缀固化，后续所有图都带同一前缀 + 同一负面提示词。

## 提示词 4-B — 主角序列帧（四方向 + 走/待机）

【目标工具】Stable Diffusion
【使用时机】风格定调后
【提示词正文】

**说明**：像素角色动画帧最难的是「帧间一致」。请**不要**试图一张图出 8 帧（AI 会乱），而是：①先用 4-C 的方法出「待机站立」单帧；②用 ControlNet 固定姿势后逐帧微调生成。下面给两个层次的提示词。

**层次 1 — 待机/站立单帧（先出基准图）：**

```
(HD-2D style, Octopath Traveler inspired, pixel art character, 16-bit retro JRPG sprite, chibi proportions, bold outlines, vibrant colors, coherent color palette, no background, plain white background), a young male traveler adventurer, brown hair, blue cloak, holding a small handheld portal device, front view, standing pose, full body, centered, single sprite
```

**层次 2 — 走/待机动作帧（用 ControlNet 保持一致性）：**

```
(HD-2D style, Octopath Traveler inspired, pixel art character, 16-bit retro JRPG sprite, chibi proportions, bold outlines, vibrant colors, coherent color palette, no background, plain white background), the same young male traveler adventurer, brown hair, blue cloak, running pose, frame 3 of 8, side view, full body, single sprite
```

**ControlNet 建议（关键）：**
1. 把层次 1 出的基准图作为 `img2img` 底图，`denoising strength` 设 `0.55–0.7`。
2. ControlNet 用 `OpenPose`（传一个走/跑姿势骨架）或 `Lineart`（锁定轮廓），权重 `0.8–1.0`，保证脸型、配色、衣服不变，只变动作。
3. 每帧只改「姿势描述」与「frame N of 8」，其余词**逐字不动**，并用同一 seed。

【预期产出】同一角色的 8 帧跑步图 + 8 帧待机图，帧间动作连贯、脸型配色一致。

## 提示词 4-C — 主角四方向（下/左/右/上）

【目标工具】Stable Diffusion
【使用时机】出完正面基准后
【提示词正文】

用同一个 seed 与同一风格前缀，只改「朝向」词，逐张出：

```
(HD-2D style, Octopath Traveler inspired, pixel art character, 16-bit retro JRPG sprite, chibi proportions, bold outlines, vibrant colors, coherent color palette, no background, plain white background), a young male traveler adventurer, brown hair, blue cloak, holding a small handheld portal device, [back view | left side view | right side view], standing pose, full body, single sprite
```

- 把 `[back view | left side view | right side view]` 分别替换为三个方向。
- 建议配合 ControlNet（把正面图转成 back/side 的轮廓）或对正面图做 `img2img`。

【预期产出】四个方向的站立基准图，与现有 `Assets/素材/{idle,down,run,left}` 结构对应，可直接替换/补充。

## 提示词 4-F — 场景 Tile（地面/墙壁/机关）

【目标工具】Stable Diffusion
【使用时机】搭建关卡地图前（配合 06 号文件）
【提示词正文】

**说明**：场景 tile 需要「可平铺 + 俯视角」，建议生成后人工做成 tile 图集，或让 SD 出可无缝平铺的纹理。

【预期产出】可平铺的场景纹理，配合 Unity Tilemap 使用。

## 提示词 4-H — 生成后如何导入 Unity（切图规范）

【目标工具】Codely（或你自己照做）
【使用时机】拿到序列帧图后
【提示词正文】

```
请给我一套「把 Stable Diffusion 生成的像素角色序列帧导入 Unity 并做成动画」的规范步骤。要求：

1. 单帧图：在 Unity 里选中 png，Sprite Mode 设为 Single，Pixels Per Unit 设置建议值（配合你的世界缩放），Filter Mode 用 Point（no filter，保持像素锐利），Compression 用 None（避免像素糊掉）。
2. 多帧图（spritesheet）：Sprite Mode 用 Multiple，Sprite Editor 里 Grid Slice 按帧切分（8 帧就切 8 格），说明如何保证切片对齐。
3. 四方向动画：把 idle/run 各方向帧做成 Animator 的 Animation Clip（如 Idle_Down、Run_Left 等），并给出 Animator Controller 参数（Speed、Direction）与状态切换逻辑。
4. 与现有 PlayerMove.cs / 现有 Assets/素材 的 idle/down/run/left 结构对齐，说明如何替换旧素材不破坏动画。
5. 兼容点：Unity 2022.3，别用 Unity 6 语法。

请给出逐步操作说明与必要的 Animator 配置建议，先不写 C#（除非需要）。
```

【预期产出】清晰的切图与动画制作步骤，替换素材后动画可正常播放。
