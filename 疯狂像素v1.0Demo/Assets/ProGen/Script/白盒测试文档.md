## 测试概述

### 测试目标
- 验证代码逻辑的正确性
- 确保所有分支和路径都被测试
- 发现潜在的bug和边界情况
- 验证异常处理机制

### 测试范围
- 核心游戏逻辑模块
- UI系统模块
- 战斗系统模块
- 资源管理系统模块

### 测试工具
- Unity Test Framework
- Unity Editor Console（用于查看Debug.Log）
- 手动测试

## 测试方法

### 1. 语句覆盖（Statement Coverage）
确保每条代码语句至少执行一次

### 2. 分支覆盖（Branch Coverage）
确保每个if/else分支都被测试

### 3. 路径覆盖（Path Coverage）
测试所有可能的执行路径

### 4. 条件覆盖（Condition Coverage）
测试所有布尔表达式的真假值组合

```csharp
using NUnit.Framework;
using UnityEngine;
using UnityEngine.TestTools;

public class CoinSystemTests
{
    [SetUp]
    public void SetUp()
    {
        // 每个测试前重置CoinSystem
        CoinSystem.ResetCoins();
    }

    [Test]
    public void AddCoins_正常增加金币_应该成功()
    {
        // Arrange
        int initialCoins = CoinSystem.CoinCount;
        int amountToAdd = 10;

        // Act
        CoinSystem.AddCoins(amountToAdd);

        // Assert
        Assert.AreEqual(initialCoins + amountToAdd, CoinSystem.CoinCount);
    }

    [Test]
    public void AddCoins_负数或零_应该不增加()
    {
        // Arrange
        int initialCoins = CoinSystem.CoinCount;

        // Act
        CoinSystem.AddCoins(-5);
        CoinSystem.AddCoins(0);

        // Assert
        Assert.AreEqual(initialCoins, CoinSystem.CoinCount);
    }

    [Test]
    public void SpendCoins_金币充足_应该成功()
    {
        // Arrange
        CoinSystem.AddCoins(20);
        int amountToSpend = 10;

        // Act
        bool result = CoinSystem.SpendCoins(amountToSpend);

        // Assert
        Assert.IsTrue(result);
        Assert.AreEqual(10, CoinSystem.CoinCount);
    }

    [Test]
    public void SpendCoins_金币不足_应该失败()
    {
        // Arrange
        CoinSystem.AddCoins(5);
        int amountToSpend = 10;

        // Act
        bool result = CoinSystem.SpendCoins(amountToSpend);

        // Assert
        Assert.IsFalse(result);
        Assert.AreEqual(5, CoinSystem.CoinCount);
    }
}
```
